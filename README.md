# Sistema de Apoio a Decisão em Análise e Predição de Série Temporal

Este projeto realiza a análise de uma série temporal de temperaturas médias diárias. 
O programa utiliza os dados de um arquivo CSV para realizar a decomposição da série, 
calcular distâncias entre subsequências, encontrar subsequências semelhantes e fazer 
uma previsão do próximo ponto da série.

## Objetivo

O objetivo do projeto é aplicar conceitos de análise de séries temporais, incluindo:

- Decomposição de uma série temporal;
- Identificação de tendência, sazonalidade e ruído;
- Cálculo de distância Euclidiana;
- Cálculo de distância de Manhattan;
- Cálculo de correlação de Pearson;
- Cálculo de correlação de Spearman;
- Busca pelas três subsequências mais próximas;
- Predição do próximo ponto da série temporal;
- Geração de gráficos para visualização dos resultados.

## Tecnologias utilizadas

O projeto foi desenvolvido em Python utilizando as seguintes bibliotecas:

- **Python 3**
- **Pandas**
- **Matplotlib**
- **Statsmodels**
